Baketopia multi-page website

Pages: index.html (Home), menu.html (Menu), about.html (About), order.html (Order), contact.html (Contact).
Shared files: style.css and script.js. Keep all files in the same folder.

Open index.html in a browser, or open the folder in VS Code and use Live Server.
The contact form is a demo and does not send messages. Replace the example email/social links with your real details.
